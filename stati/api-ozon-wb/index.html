API Озон и Вайлдберриз для селлера: что автоматизировать без программиста

API Озон (Ozon Seller API) — это официальный способ, которым программа или сервис работает с вашим магазином без ручных кликов в личном кабинете: обновляет остатки и цены, забирает заказы, выгружает отчёты, отвечает на отзывы. Ключ создаётся в кабинете Ozon в разделе «Настройки → Seller API», у Вайлдберриз — токен в разделе «Интеграции по API». Писать код для этого не обязательно. Ключ можно отдать готовому сервису из каталога площадки, подключить Google-таблицу или ИИ-агента.

Коротко

  • API — «розетка» магазина для программ. Через неё сервис делает то же, что вы руками в кабинете, только за секунды и без ошибок копирования.
  • Ozon: ключ — в «Настройки → Seller API», для рекламы отдельный — «Performance API». С 3 сентября 2026 новые ключи Ozon действуют 3 месяца.
  • WB: токен — в «Интеграции по API», живёт 180 дней, показывается один раз. Всего до 20 активных токенов.
  • Главное правило безопасности — минимум прав. Сервису аналитики хватит «только чтения».
  • У каждого метода есть лимит запросов. Превысили — получите ошибку 429 и ждёте.

Что такое API простыми словами

Личный кабинет сделан для человека: кнопки, таблицы, фильтры. API — тот же магазин, но для программ. Программа отправляет запрос «дай заказы за сегодня» или «поставь остаток 15 на артикул», а площадка отвечает данными.

Ozon объясняет это так: API — посредник между двумя системами, который позволяет им обмениваться данными без доступа к коду друг друга (База знаний Ozon). У WB смысл тот же: сторонние сервисы и ваши программы обмениваются информацией с магазином (справочный центр WB).

Что это даёт селлеру: меньше рутины и меньше ошибок. Ozon в своей статье приводит пример: обновить остатки у 10 000 товаров вручную — десятки человеко-часов, через API — несколько секунд.

Как получить API-ключ Озон

По Базе знаний Ozon:

  1. В правом верхнем углу кабинета откройте «Настройки».
  2. Перейдите в раздел «Seller API» и нажмите «Сгенерировать ключ».
  3. Укажите название, цель использования и, если ключ для внешнего сервиса, его название.
  4. Выберите роль. Роль ограничивает, какие методы доступны этому ключу.
  5. Нажмите «Сгенерировать».

В запросах вместе с ключом используется Client ID вашего магазина. Что важно на октябрь 2026:

  • Срок ключей. С 3 сентября 2026 года новые ключи создаются на 3 месяца. Старые «бессрочные» тоже получили срок в 3 месяца. Поставьте напоминание, иначе интеграция однажды утром молча перестанет работать.
  • Разрешённые сети. В настройках ключа можно задать диапазон IP-адресов, с которых он работает. Если ключ утечёт, с чужого сервера его не используют.
  • Реклама — отдельно. Для рекламного кабинета нужен Performance API: «Настройки → Performance API», там создаётся сервисный аккаунт и ключ. Лимит — не больше 100 000 запросов в сутки на сервисный аккаунт (Ozon).
  • Документация Озон API — docs.ozon.ru/api/seller. Методы можно попробовать прямо там, вписав Client ID и API Key. Ozon также выкладывает коллекцию для Postman.

Как получить токен API Вайлдберриз

По инструкции WB (правка 18.05.2026):

  1. Откройте раздел «Интеграции по API» в профиле и нажмите «+ Создать токен».
  2. Выберите вкладку: «Для сервиса из каталога» или «Для интеграции вручную».
  3. Отметьте категории данных и уровень доступа: «Чтение и запись» или «Только чтение».
  4. Нажмите «Создать», затем «Скопировать и закрыть».

У WB четыре типа токенов:

Тип Для чего
Сервисный облачный сервис из официального каталога решений WB; настройки подставятся сами
Персональный ваши программы и коробочные системы (1С, ERP) на своих серверах; передавать третьим лицам и в облачные сервисы нельзя
Базовый тестирование на реальных данных и случаи, когда другие не подходят; часть данных недоступна
Тестовый песочница без реальных данных магазина

Правила, которые проще запомнить сразу:

  • Токены создаёт и удаляет только владелец профиля.
  • Токен показывается один раз. Потеряли — удаляйте и создавайте новый.
  • Срок жизни — 180 дней, продлить нельзя. WB советует перевыпускать за 7–14 дней до конца срока кнопкой «Дублировать».
  • Категории после создания не меняются. WB не рекомендует брать больше трёх категорий в один токен.
  • Если сервис из каталога поддерживает OAuth 2.0, WB советует подключать через него. Так вы вообще не передаёте токен руками.

Какие задачи закрывает API Озон и WB

Задача WB API (категория токена) Ozon Seller API
Остатки на своём складе (FBS) «Маркетплейс» обновление остатков для FBS и realFBS
Цены и скидки, акции «Цены и скидки» цены, участие в акциях
Заказы FBS / DBS «Маркетплейс» отправления FBO, FBS, realFBS
Карточки товаров «Контент» загрузка и обновление товаров, атрибуты
Отчёты реализации, финансы «Финансы», «Статистика» отчёты по ценам, остаткам, отправлениям
Аналитика, удержания, хранение «Аналитика» аналитика (методы зависят от роли)
Отзывы и вопросы «Вопросы и отзывы» чаты с покупателями; отзывы — уточните в документации
Реклама «Продвижение» отдельный Performance API
Поставки FBW / возвраты «Поставки», «Возвраты» склады, возвраты

Источники: категории данных WB API, База знаний Ozon.

Одна оговорка от Ozon: на FBO остатки обновлять не нужно, их учитывает сам Ozon. Самая большая экономия от API — на FBS и realFBS, где остатки живут у вас.

Лимиты: почему API «перестаёт отвечать»

У WB для каждого метода свой лимит, и зависит он от типа токена (dev.wildberries.ru). Пример из документации — категория «Маркетплейс»:

Тип токена Лимит в минуту Интервал Всплеск
Персональный, сервисный 300 запросов 200 мс 20
Базовый, тестовый 150 запросов 200 мс 10

Ещё три вещи, о которых селлеры узнают на собственном опыте:

  • Запрос с ошибкой 4XX в категории «Маркетплейс» засчитывается за 10 запросов. Кривой скрипт съедает лимит в десять раз быстрее.
  • Детализация отчёта реализации за период: 1 запрос в минуту на персональном и сервисном токене. На базовом — только 2 запроса в сутки (документация WB).
  • При ошибке 429 WB возвращает заголовок X-Ratelimit-Retry — через сколько секунд можно повторить.

У Ozon лимиты указаны в документации отдельно по методам, и общей цифры я приводить не буду — уточните в docs.ozon.ru. Точно известно одно: Performance API — до 100 000 запросов в сутки на сервисный аккаунт.

У Яндекс Маркета — не больше четырёх одновременных запросов на магазин или кабинет; при превышении сервер отвечает кодом 420 (документация Маркета). Токен Маркета создаётся в «Настройки → API и модули», действует бессрочно, в кабинете их может быть до 30.

Безопасность ключей

WB прямо пишет: токен — аналог пароля, только для программы. Что делать:

  • Давать минимум прав. Сервис аналитики — «Только чтение». Автоответчик на отзывы — только «Вопросы и отзывы».
  • Отдельный ключ под каждый сервис. Перестали работать с сервисом или разработчиком — сразу удаляйте его ключ.
  • Хранить в менеджере паролей, не в чатах и не в заметках.
  • На Ozon — ограничить ключ разрешёнными IP-сетями.
  • Не вставлять токен WB в онлайн-декодеры: WB отдельно не рекомендует смотреть токен внешними инструментами.
  • Не пользоваться «интеграциями» через логин, пароль и куки кабинета. На портале разработчиков WB сказано, что по пункту 9.9.6 оферты интеграция с порталом продавца без WB API запрещена.

Что можно сделать без программиста

Бесплатно или почти бесплатно: - Готовые сервисы из каталога решений WB и интеграций Ozon подключаются ключом за пару минут. Стоимость у всех разная. Цены я не называю: проверяйте на сайте сервиса. - Google-таблицы. В документации WB у методов детализации отчёта реализации стоит пометка, что данные можно выгрузить в Google Таблицы. - Тестовые токены и песочница WB позволяют попробовать запросы без риска для реального магазина.

Где упрётесь: - Сводить данные WB и Ozon в одну картину сервис из каталога одной площадки не будет. - Своя логика («если остаток меньше 5 и реклама крутится — выключи рекламу») в готовом сервисе часто не настраивается. - Методы устаревают. Ozon и WB регулярно отключают старые версии, и интеграцию приходится поддерживать.

ИИ-агент. Я сам подключаю ИИ-агентов на Claude к кабинету Ozon через API. Агент — это программа, которая понимает задачу словами и сама вызывает нужные методы. Селлер пишет «покажи товары, где остаток кончится за неделю», а агент забирает данные и отвечает таблицей. Кода вы при этом не пишете. Но ключ и роль выбираете вы, и агенту на старте я даю только чтение.

Что говорят селлеры в чатах

С 22 сентября по 16 октября 2026 года в чатах селлеров, которые мы читаем, было 68 разных вопросов про API и токены. Больше половины — в чате разработчиков Ozon, остальное — WB и Яндекс Маркет. Типичные проблемы:

  1. «Ошибка obsolete method cannot be used». Метод устарел и отключён, нужна новая версия. Такое случается и с готовыми сервисами, если те не обновились.
  2. «Токен не подходит» в бухгалтерии или 1С. В чатах разбирали случай: финансовые отчёты WB через базовый токен упираются в лимит 2 запроса в сутки. Совет — перевыпустить персональный токен с правами только на чтение. Это совпадает с документацией WB.
  3. «Отчёт за вчера отдаёт пустой ответ 204». Детализация WB ещё не сформирована. В чатах советуют повторять запрос несколько раз в день, а не сразу считать это ошибкой.
  4. «Насколько безопасно давать ключ сервису аналитики?» Ответ в чатах — тот же, что у площадок: только чтение, проверенный сервис, перевыпуск ключа, удаление после отказа от сервиса.
  5. «С нашего сервера не соединяется с api-seller.ozon.ru». Похоже на сетевые ограничения со стороны сервера или хостинга. Решается сменой хостинга или сети, а не ключа. Я сам с этим сталкивался.

Частые вопросы

Где найти Client ID и API-ключ Ozon? «Настройки → Seller API». Там же генерируется ключ и выбирается роль.

Сколько действует ключ API Озон? С 3 сентября 2026 года — 3 месяца, и для новых ключей, и для бывших бессрочных.

Сколько действует токен WB API и можно ли его продлить? 180 дней. Продлить нельзя: создаёте новый кнопкой «Дублировать», переключаете интеграцию, потом удаляете старый.

Для второго магазина нужен отдельный ключ? В чатах отвечают так: да, у каждого магазина свой Client ID, и ключ создаётся в настройках именно этого магазина. В Базе знаний Ozon я прямого ответа не нашёл, поэтому проверьте в своём кабинете.

Какой токен WB выбрать для 1С на своём компьютере? По инструкции WB — персональный. Для облачного сервиса из каталога — сервисный.

Нужен ли программист, чтобы пользоваться API? Чтобы подключить готовый сервис или Google-таблицу — нет. Свою логику на стыке нескольких площадок проще собрать с ИИ-агентом или разработчиком.
