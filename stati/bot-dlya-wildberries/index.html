Бот для Вайлдберриз: какие полезны селлеру, а какие опасны

Бот для Вайлдберриз безопасен, когда подключается к кабинету через официальный API по токену: присылает в Telegram заказы, остатки, новые отзывы, баланс и коэффициенты приёмки. Опасен бот, который просит телефон и код из СМС или работает через расширение браузера. Так устроено большинство автобронировщиков слотов. По оферте WB подключать стороннюю программу к порталу можно только через публичный API (п. 9.9.6), всё остальное запрещено (п. 9.9.7). Ниже разбираю, какие боты брать, как проверить бота за пять минут и что можно сделать бесплатно.

Коротко

  • Полезные боты читают данные по API-токену. Токен вы создаёте сами, выбираете категории данных и уровень доступа «только чтение». Отозвать его можно в один клик.
  • Метода, который бронирует дату поставки FBW, в публичном API WB я не нашёл: там есть коэффициенты приёмки и черновики поставок. Поэтому автобронь обычно работает через ваш логин или браузер, то есть в обход п. 9.9.6 оферты.
  • Бот, который только следит за слотами и пишет вам в Telegram, укладывается в правила. Бронируете вы потом сами, руками.
  • Никому не отдавайте шестизначный код входа, даже «поддержке». Об этом прямо пишет WB в памятке о мошенниках.
  • В чатах селлеров с 22 сентября по 18 октября 2026 года про боты для ловли слотов WB спросили около 20 раз. Трижды спрашивали, не заблокируют ли за это кабинет.

Какие боты для Вайлдберриз реально полезны

Почти всё полезное, что делает бот для селлера, сводится к одному: забрать данные из кабинета и вовремя показать их человеку. Для этого у WB есть 13 категорий данных API, и каждая открывает свой кусок кабинета (справка WB «Категории данных WB API», правка 26.08.2026). API здесь — официальный вход в кабинет для программ: бот получает ровно то, что вы разрешили, и ничего больше.

Пример из самой справки WB: сервис, который присылает в Telegram уведомление о каждом новом отзыве, должен получить только категорию «Вопросы и отзывы». Такой бот не видит ни ваших денег, ни карточек.

Про деньги и удержания подробно писал отдельно: выплаты Вайлдберриз и штрафы Вайлдберриз. Бот на категории «Статистика» как раз ловит такие строки в отчёте в день появления.

Бот для бронирования слотов ВБ: в чём риск

Это самый частый запрос и самый рискованный вид ботов. Разберу, как устроены правила.

Что говорит оферта. В разделе 9 оферты WB («Правила использования портала», правка 01.10.2026) есть два пункта. По п. 9.9.6 продавец может подключать стороннюю программу к порталу автоматически «только при помощи Публичного API». По п. 9.9.7 продавцу нельзя подключаться к порталу иначе. Ещё по этому пункту нельзя давать третьим лицам ключи доступа к порталу для целей, которые оферта не предусматривает.

Как сейчас планируют поставку FBW. В кабинете продавец выбирает пункт отгрузки и дату. Склад хранения выбрать нельзя: после приёмки WB сам распределит товар по складам (справка WB «Как создать поставку», правка 29.09.2026). «Поймать слот» — значит успеть взять свободную дату на нужном пункте с низким коэффициентом.

Что есть в API по поставкам. Коэффициенты приёмки по складам и датам отдаёт метод из раздела «Тарифы» (документация WB API). В разделе «Поставки FBW» есть методы для черновиков, складов, вариантов приёмки и статусов поставок. Метода, который бронирует дату, я там не нашёл. Точные лимиты запросов и поля ответа смотрите в документации WB API: они меняются.

Что из этого следует. Бот, который сам ставит поставку на дату, не может сделать это через публичный API. Значит, он заходит в кабинет под вами: по телефону и коду, через сохранённую сессию или через расширение браузера. Именно такую схему WB описывает в памятке о мошенниках: программа или расширение «запрашивают токен API или код из СМС» (справка WB). Про расширения WB отдельно предупреждает: по уровню доступа установка расширения «почти равна установке приложения на телефон», а после тихого обновления оно может начать работать иначе (справка WB о безопасной работе с данными).

Что будет за автобронь. Отдельной статьи в справочном центре про автобронирование и про санкцию за него я не нашёл. Отдельного штрафа за автобронь нет и в перечне штрафов WB (правка 13.10.2026). Риск в другом: работа в обход API прямо запрещена п. 9.9.7. А бот с вашим кодом входа может делать в кабинете вообще всё, а не только ловить слоты.

Что можно без риска. Бот, который регулярно проверяет коэффициенты по нужным складам и пишет в Telegram: «Коледино, короба, бесплатная приёмка на 24.10». Это обычный API, токен без права записи, бронь руками за минуту.

Бот бронирования поставок ВБ бесплатно: что реально и где упрётесь

Запрос «бесплатно» понятен: слоты ловят неделями. Вот что есть без денег.

  1. «Помощник» внутри WB Partners. Это собственный бот WB в приложении и веб-версии. Без подписки «Джем» в приложении доступны 1 запрос данных о товаре в день, 1 мониторинг и ИИ-чат по справке и бесплатным отчётам (справка WB «Помощник», правка 24.09.2026). Мониторинг — это отчёт, который сам приходит в чат по расписанию или когда показатель перешёл порог. Слоты он не ловит: это бот про аналитику товаров.
  2. Свой бот на коэффициентах приёмки. Метод открыт в публичном API. Собрать такого бота можно за вечер, если у вас есть человек, который пишет код, или ИИ-ассистент, который напишет код за вас. Упрётесь в одно: бронь всё равно руками.
  3. Бесплатные автобронировщики в Telegram. Здесь бесплатность часто означает, что вы платите доступом к кабинету. Если бот просит телефон и код — это ровно та схема, от которой предостерегает WB.

Где упрётесь в любом случае: бот не создаёт слоты. Если склад не принимает вашу категорию или приёмки нет совсем, бот будет молчать неделями, и это не поломка. В чатах селлер жаловался, что бесплатный бот молчит второй месяц, и спрашивал, может ли на СЦ правда не быть свободных дат.

Как проверить бота за пять минут

Перед подключением любого бота для Вайлдберриз пройдите по списку.

  • Как он подключается? Нормально — токен API или подключение через OAuth 2.0 из каталога. OAuth — способ, при котором вы подтверждаете доступ в кабинете WB и не копируете токены руками. Ненормально — телефон, код из СМС, логин сотрудника.
  • Есть ли он в каталоге решений WB? У WB есть каталог готовых решений, а в кабинете — список проверенных сервисов. Для сервиса из каталога создаётся сервисный токен, привязанный только к нему.
  • Какие категории он просит? Боту для отзывов не нужны «Финансы». WB советует давать для персонального токена не больше 3 категорий и только нужные.
  • Хватит ли «только чтения»? Если бот только уведомляет, право записи ему не нужно.
  • Отдельный токен на каждый бот. Так рекомендует WB: отключили один сервис — остальные работают.
  • Срок 180 дней. Токен живёт 180 дней. За 3 дня до конца WB присылает уведомление. Сменили телефон владельца — все токены придётся перевыпустить (справка WB о создании токена, «Как подключиться по API через токен»).
  • Закончили работать с сервисом — удалите токен сразу. Создавать и удалять токены может только владелец кабинета.

Ещё одна деталь: персональный токен нельзя передавать третьим лицам и использовать в облачных сервисах. Он для ваших собственных программ на ваших или арендованных серверах (справка WB «Как подключиться по API через токен»). Если чужой бот в Telegram просит именно персональный токен, это повод насторожиться.

Что спрашивают про ботов в чатах селлеров

Мы читаем более 200 Telegram-чатов селлеров WB и Ozon. С 22 сентября по 18 октября 2026 года там было около 11 400 разных вопросов. Про боты для ловли и брони слотов на WB из них — около 20. Ещё 4 — про такие же боты для Ozon и Яндекс Маркета. О чём спрашивают:

  • «Посоветуйте рабочий бот для поставок». Это большинство вопросов. Конкретные склады: Коледино, Электросталь, Тула, Новосемейкино, Краснодар.
  • Риск блокировки — 3 вопроса. «Нет риска блокировки кабинета?», «не банят ли из-за автоброни?». В одном случае селлер написал, что после подключения бота на автобронирование кабинет заблокировали, и сам не понял, WB это или мошенники.
  • Бесплатность — 2 вопроса. «Бот для бронирования слотов бесплатный?» и «бесплатный бот молчит — есть ли смысл в платном?».

Ответы в чатах расходятся. Одни пишут, что такие боты запрещены офертой (ссылаются на п. 9.8, в действующей редакции это п. 9.9.6–9.9.7). Другие пишут, что WB не блокирует кабинет целиком, а на время закрывает создание поставок. Подтверждения этому в справке WB я не нашёл. Третьи пишут, что пользуются ботами годами без проблем. Сходятся в одном: ключ доступа с ограниченными правами отдать можно, логин и код — нельзя.

И ещё одно наблюдение из тех же чатов. За этот период 65 раз всплыло одно и то же сообщение: «кто-нибудь проверял, как работают эти боты?» с тремя ссылками и случайным хвостом в конце. Это реклама, замаскированная под вопрос. Про качество ботов по ссылкам она ничего не говорит.

Автоматизация Вайлдберриз: что я делаю с ботами и ИИ

Я собираю Telegram-ботов и ИИ-агентов на Claude и подключаю ИИ к кабинету Ozon через API. Агент — программа, которая сама выполняет цепочку шагов: забрала данные, разобрала, прислала вывод. На WB логика та же, и вот что в ней работает без программиста в штате.

  • Сводка в Telegram раз в день. Заказы, остатки, которые скоро кончатся, баланс, новые штрафы. Один токен «только чтение» на нужные категории.
  • Слежение за слотами. Бот проверяет коэффициенты по вашим складам и типу поставки и пишет, как только появилась дешёвая приёмка. Бронь — руками.
  • Отзывы. Бот присылает новый отзыв, нейросеть пишет черновик ответа, человек нажимает «отправить». Без человека я бы ответы не публиковал. Почему — в статье ответ на отзыв нейросетью.
  • Код для бота. Его можно попросить у ИИ-ассистента: метод, лимиты и формат ответа описаны в документации WB. Что ещё автоматизировать через API, разбирал в статье API Озон и WB для селлера.

Чего ИИ не сделает: не найдёт слот там, где склад закрыт; не обойдёт лимит запросов; не сделает автобронь законной. И не заменит решение «везти на этот склад с этим коэффициентом или ждать» — его принимает человек, который знает свою экономику.

Частые вопросы

Есть бот для бронирования слотов на ВБ бесплатный? Бесплатно можно собрать бот, который следит за коэффициентами приёмки по API и пишет вам в Telegram. Бронировать придётся руками: метода брони даты в публичном API WB нет. Бесплатные автобронировщики обычно просят доступ к кабинету.

Могут ли заблокировать кабинет за автобронь? Отдельной санкции за автобронь в справочном центре WB я не нашёл. Но оферта разрешает подключать программы только через публичный API (п. 9.9.6) и запрещает другие способы (п. 9.9.7). В чатах один селлер написал, что кабинет заблокировали после подключения такого бота, но причину он сам не знает.

Можно отдать боту телефон и код из СМС? Нет. WB прямо пишет: никому не сообщайте шестизначный код, даже поддержке. Нормальный бот работает по токену API, который вы создали сами с нужными категориями.

Как настроить, чтобы бот присылал новые отзывы в Telegram? Создайте в разделе «Интеграции по API» токен с одной категорией «Вопросы и отзывы» и уровнем «только чтение». Этот токен введите в боте. Отвечать бот сможет, только если дать ему право записи.

Почему бот ловли слотов молчит неделями? Бот не создаёт слоты, он только показывает их. Если склад закрыт для приёмки или не принимает ваш тип поставки, слотов нет ни у кого. Добавьте соседние склады или другой тип поставки.

Есть ли бот для мониторинга соинвеста на Озоне? Это вопрос про Ozon, а не про WB. В чатах селлеров за тот же период про соинвест спросили 31 раз, про бота для него — один раз. Метода API под соинвест в документации Ozon я не проверял, поэтому уточните в базе знаний Ozon, какие данные по акциям отдаёт Seller API.
